# Trắc Nghiệm Xã Hội Học Đại Cương

Trang web thi trắc nghiệm môn Xã hội học đại cương:
- **Đề thi 50 câu ngẫu nhiên** được lấy từ ngân hàng câu hỏi.
- **Thời gian làm bài: 60 phút**.
- **Thang điểm 10**: Đúng 50/50 câu đạt 10.0 điểm (mỗi câu đúng 0.2 điểm).
- **Tự động xáo trộn câu hỏi và đảo thứ tự 4 đáp án** mỗi lần thi, không bị trùng lặp.
- **Tự động lưu lịch sử các lần thi** trực tiếp trên trình duyệt (sử dụng `localStorage`).
